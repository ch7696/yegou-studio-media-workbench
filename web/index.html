这里有两条独立流水线。根据你现在要做的事情选择入口，页面会按顺序带你走完每一步。

01 / VOICE ASSETS

识别并提取语音资产

声

上传一段音频或视频，识别里面有哪些说话人，清洁并截取每个人的参考音色，最后保存成可以反复使用的资产。

导入音频或视频 选择原始素材
识别说话人 ASR + 说话人聚类
清洁并切片 生成每个说话人的参考音频
保存资产 输出到 F:\voice
适合先把素材整理成音色库进入资产流水线 →
02 / DUBBING

按说话人替换视频配音

配

导入需要处理的视频，自动生成说话人时间轴。筛选一个说话人，绑定参考音色，逐句试听或一次替换他的全部台词，保留背景和音效后导出。

导入视频 原视频不会被覆盖
分析音轨 人声 / 背景两路分离
筛选说话人 查看完整台词和时间戳
绑定并试听 参考音色 + 新台词
批量替换并导出 保留背景与音效
适合整段视频的目标人物替换进入配音流水线 →
输出统一所有项目结果保存到 Windows 的 F:\voice，原始文件不覆盖。
模型分工识别使用 Qwen3-ASR + 说话人模型，配音使用 CosyVoice3。
